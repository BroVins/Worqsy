## Deliberately not treated as mature enterprise features

The following are intentionally left as extension points rather than presented as enterprise-complete capabilities:

- complex custom workflow builder
- advanced custom fields UI
- recurring-task scheduler
- dependency graph engine
- S3 production setup wizard
- realtime WebSocket chat
- complex portfolio analytics
- AI features
- billing/subscription
- enterprise SSO
- marketplace/plugin ecosystem

These items align with later product directions rather than the simplest initial core.
